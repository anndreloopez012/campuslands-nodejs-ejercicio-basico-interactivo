Evaluación Diagnóstica Backend en Entorno Offline (Sin Internet)
 Examen: Backend Node.js · SQL · Fundamentos IA
Duración: 120 minutos | Modalidad: Individual
Destinatario: Técnico de Laboratorio / Tutor
Objetivo: Salón 100% blindado para trabajo local
⚠️ REGLA CRÍTICA DE LA PRUEBA: Los alumnos trabajarán estrictamente sin conexión a internet y deberán crear su solución desde cero (npm init -y). Si no se ejecuta el precalentamiento del caché de npm y la configuración de PostgreSQL/MySQL local, npm install express fallará con error de red y la evaluación se interrumpirá.

1. Software Base Obligatorio por Computadora

Software Versión Parámetros de Instalación / Verificación
Node.js + npm v18.0+ o v20 LTS Vital Descargar de nodejs.org. Marcar "Add to PATH". Verificar en terminal con node -v.
PostgreSQL (o MySQL) v15 / v16 Recomendado Servicio activo en puerto 5432. Usuario: postgres | Contraseña: postgres (o campuslands).
Visual Studio Code Última estable Editor principal de código con extensiones preinstaladas (ver Sección 3).
DBeaver Community Última estable Cliente gráfico SQL para que el alumno explore tablas y ejecute database.sql.
Compresor ZIP Nativo / 7-Zip Para generar el entregable final comprimido .zip sin la carpeta node_modules.

2. El Paso Maestro: Pre-calentar el Caché de npm (Vital para Modo Offline)

Cuando un alumno haga npm install express dotenv pg sin internet, npm acudirá a su caché local en disco. Si ejecutamos este comando previo con conexión, los paquetes se instalarán en 2 segundos sin tocar internet:

A. En Windows (PowerShell como Administrador):

mkdir C:\temp-warmup; cd C:\temp-warmup; npm init -y; npm install express dotenv pg mysql2 cors nodemon; cd C:\; Remove-Item -Recurse -Force C:\temp-warmup

B. En Linux / macOS (Terminal):

mkdir -p /tmp/npm-warmup && cd /tmp/npm-warmup && npm init -y && npm install express dotenv pg mysql2 cors nodemon && cd /tmp && rm -rf /tmp/npm-warmup
💡 ¿Qué hace este paso? Descarga en el almacenamiento local permanente de npm (%LocalAppData%\npm-cache o ~/.npm) todos los paquetes típicos de backend. Durante la prueba offline, npm los servirá automáticamente desde el disco duro.

3. Extensiones Obligatorias en Visual Studio Code

Postman suele bloquearse, congelarse o solicitar login online si no detecta red. Por ello, debemos dejar VS Code equipado para pruebas de API locales:

Extensión ID de Instalación Utilidad durante la Evaluación
REST Client Imprescindible humao.rest-client Permite probar POST /incidents, GET y PATCH desde archivos .http con un clic.
Thunder Client rangav.vscode-thunder-client Cliente visual tipo Postman integrado dentro de VS Code (funciona 100% offline).
Prettier esbenp.prettier-vscode Formateador automático de código (evaluado en legibilidad del proyecto).

Comando CLI para instalarlas en lote desde la terminal:

code --install-extension humao.rest-client --install-extension rangav.vscode-thunder-client --install-extension esbenp.prettier-vscode

4. Configuración de la Base de Datos SQL Local en cada PC

El examen exige crear tablas para usuarios e incidentes. El técnico debe asegurar que el motor esté corriendo localmente:

Opción A: PostgreSQL (Recomendada)

1. Verificar que el servicio esté iniciado en Windows (Servicios ➔ postgresql-x64-XX ➔ Iniciar).

2. Crear la base de datos para el examen ejecutando:

psql -U postgres -c "CREATE DATABASE incidents_db;"

3. Credenciales: Host: localhost:5432 | User: postgres | Clave: postgres.

Opción B: MySQL (XAMPP / Server)

1. Verificar en XAMPP que el módulo MySQL esté en verde (puerto 3306).

2. Crear la base de datos para el examen ejecutando:

mysql -u root -e "CREATE DATABASE incidents_db;"

3. Credenciales: Host: localhost:3306 | User: root | Sin contraseña.

5. Pruebas Automatizadas sin Internet (Requisito Obligatorio #9)

💡 VENTAJA TÉCNICA CLAVE: No intente instalar Jest o Mocha. Node.js v18/20+ incluye de forma nativa el motor node:test y las aserciones node:assert. Los alumnos solo deben importar import test from 'node:test' y ejecutar node --test en la terminal. Funciona al 100% sin dependencias ni internet.

6. Nota de Credenciales para el Alumno (Dejar en el Escritorio)

Cree un archivo llamado DATOS_LOCALES_EXAMEN.txt en el Escritorio de cada computadora con esta información:

======================================================================
CAMPUSLANDS - DATOS DE ENTORNO LOCAL PARA EVALUACIÓN BACKEND
======================================================================
1. BASE DE DATOS LOCAL:
   - Motor: PostgreSQL | Host: localhost:5432 | BD: incidents_db
   - Usuario: postgres | Contraseña: postgres (o campuslands)

2. CÓMO PROBAR ENDPOINTS SIN POSTMAN (Extensión REST Client):
   - Crea un archivo 'requests.http' en tu proyecto en VS Code.
   - Escribe tu endpoint (ej: GET http://localhost:3000/incidents).
   - Haz clic sobre el enlace azul 'Send Request' que aparece sobre la línea.

3. PRUEBAS AUTOMATIZADAS (Cero librerías externas necesarias):
   - Usa el módulo nativo de Node.js: import test from 'node:test';
   - Ejecuta tus pruebas en terminal con: node --test

4. ENTREGA FINAL:
   - Comprime tu solución en un archivo .zip
   - REGLA: NO incluyas la carpeta 'node_modules' en el .zip entregado.
======================================================================

7. "Prueba de Fuego" y Checklist de Certificación Técnica

Antes de habilitar el salón, el técnico debe realizar esta prueba de 60 segundos con el Wi-Fi apagado y el cable de red desconectado:

 1. Desconexión de Red Desconectar cable Ethernet y apagar Wi-Fi en el equipo.
2. Prueba de npm Offline Ejecutar en terminal: mkdir test-offline && cd test-offline && npm init -y && npm install express dotenv pg.
Debe instalarse en menos de 5 segundos sin errores. Luego borrar la carpeta.
3. Conexión SQL en DBeaver DBeaver conecta exitosamente a localhost:5432 (o 3306) y visualiza la base incidents_db.
4. Extensión REST Client VS Code tiene activa la extensión REST Client para probar peticiones HTTP.
5. Archivo en el Escritorio El archivo DATOS_LOCALES_EXAMEN.txt está ubicado y visible en el Escritorio.
6. Limpieza Previa Papelera vacía y sin proyectos residuales previos para que el camper inicie limpio.
